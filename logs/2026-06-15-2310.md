# Journal de conseil — 2026-06-15 23:10

**Question :** « L'immigration clandestine est-elle un danger pour la sécurité dans le pays ? » (France)

## Routage
- **Niveau :** COMPLEXE
- **Grounding requis :** oui
- **Justification :** question hautement sensible (politique, sécurité publique), nécessite données factuelles et sources fiables pour éviter biais idéologiques.

## Dossier de faits (empiriste — sources réelles)
Points structurants vérifiés :
- Statistique publique FR **ne distingue pas réguliers/irréguliers** dans la délinquance (ministère Intérieur, réponse Sénat oct. 2024). Part des irréguliers dans la délinquance **impossible à établir**.
- Étrangers = 8,8 % population (INSEE 2024) ; irréguliers ~1 % (~600 000 ; proxy AME ~465 000).
- Étrangers = 17 % des mis en cause (SSMSI 2024), mais « mis en cause » ≠ condamnés ; dénominateur INSEE biaisé (DéFACTO).
- Biais : contrôles au faciès (×6/×8, Open Society/CNRS) ; disparités judiciaires (×5 détention provisoire, OIP/CEPII) ; âge/sexe confondants.
- Causalité : Marie & Pinotti (JEP 2024, 55 pays) → pas d'effet causal ; CEPII → « illusion » ; régularisation italienne → ÷2 délinquance.
- Terrorisme : 78 % impliqués 2014-2020 = Français ; cas réels d'étrangers récents/irréguliers (Nice 2020) ; statut administratif des terroristes non publié.
- Vulnérabilité : 2 100 victimes de traite (2023, +6 %) ; >90 % migrants irréguliers via passeurs ; irréguliers = surtout victimes.

## Cartes (Stage 1) — table interne (non transmise au Stage 2)
- **A = hypersystematique** : glissement de catégorie (étrangers ≠ irréguliers) + « sécurité » non définie → conclusion tranchée invalide. Confiance élevée.
- **B = adversaire** : « pas de danger » non établi, seulement non démontré ; incertitude bilatérale. Confiance moyenne.
- **C = pragmatique** : leviers efficaces = réseaux + précarité, pas le volume ; politique par statut mal ciblée. Confiance moyenne.
- **D = divergent** : la clandestinité (produit du droit) est le vecteur ; inversion causale. Confiance moyenne.

## Revue croisée (Stage 2, sur cartes anonymisées)
Classement : **A > D > C > B**.

## Débat focalisé (B vs D)
- B : inversion causale = 1 étude italienne (n=1), non transférable → incertitude rigoureuse.
- D : incertitude asymétrique ; mécanismes (passeurs, régularisation, précarité) documentés indépendamment ; invisibilité = signature du mécanisme.
- Convergence : désaccord sur le **degré de certitude**, pas sur le rôle du migrant.

## Synthèse (chairman)
- **Majorité :** question non tranchable en l'état des données ; incertitude = seule position rigoureuse ; rien n'incrimine la personne migrante. Confiance élevée sur le diagnostic, faible sur toute réponse tranchée.
- **Dissidence (D) préservée :** le vecteur est la clandestinité elle-même, pas la migration ; incertitude possiblement asymétrique.
- **Bascule :** stats réguliers/irréguliers sur condamnations (contrôle âge/sexe) ; publication du statut administratif des terroristes ; réplication hors Italie ; définition de « sécurité ».
- **Confiance globale :** MOYENNE. Piège : « non démontré » ≠ « démontré faux ».

## Drapeaux non levés
Part des irréguliers inconnue (structurel) ; statut des terroristes non publié ; asymétrie vs symétrie de l'incertitude non tranchée ; transférabilité régularisation IT→FR non établie ; 17 % ≠ mesure de criminalité réelle ; « sécurité » non définie.

## Avertissement
Faux consensus mono-Claude possible : la convergence des cartes valide seulement que les données ne permettent pas de conclure, pas une thèse sur le réel.
